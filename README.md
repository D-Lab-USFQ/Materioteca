# Materioteca

La Materioteca del D.Lab es una colección de materias primas locales transformadas mediante procesos como deshidratado, molido y liofilizado. Estos insumos se utilizan para la creación de tintes y para aportar distintas propiedades a los materiales biofabricados en el laboratorio. 
Este repositorio permite explorar sus características y a su vez, facilita el acceso a la información generada en los proyectos del D.Lab. La Materioteca consolida resultados de investigación aplicada y fomenta nuevas posibilidades de experimentación, diseño y desarrollo.
